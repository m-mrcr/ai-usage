Features

Privacy by design

Clear about what it reads and where it connects.

AI Usage only handles what's needed to fetch usage data. It never saves OAuth tokens or local log contents to its settings, snapshots, or regular logs.

Codex / Grok

Reads the usage logs each tool already saves on your Mac. No API calls or token usage involved.

Claude Code

Uses Claude Code's credentials from macOS Keychain, and only contacts Anthropic's usage API when fetching usage data.

Main app / Widget

The main app collects data and passes only a minimal display snapshot to the Widget via an App Group.

Local access

The main app is unsandboxed because it needs to read each tool's logs. It parses the tail of the log in memory, and never stores or sends conversation content or raw lines.

Install

Get started in 5 steps.

macOS 14 Sonoma or later. Install the DMG manually the first time; after that, check for updates from within the app.

  1. 1
    Get it and install it

    Verify the SHA-256 on the official page, then drag AI Usage from the DMG to Applications.

  2. 2
    Set up the tools you use

    Sign in to Claude Code. For Codex and Grok, complete one normal response so they create a log.

  3. 3
    Launch AI Usage

    Usage is checked automatically. If macOS prompts you, confirm it's the notarized distribution before allowing Claude Code's Keychain access.

  4. 4
    Choose language and display

    In Settings, choose Japanese or English and which agents to show, and arrange the card order in the list.

  5. 5
    Add a widget

    Choose "Edit Widgets" on macOS and add AI Usage. Keep the main app running so values stay up to date.
